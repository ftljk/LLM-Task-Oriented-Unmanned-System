## 绘制建议

1. **颜色**：每层使用不同颜色背景，箭头从上一层指向下一层
2. **宽度**：两层之间的箭头标注传递的数据类型（normalized input / TaskPlan / 校验后计划 / SetVelocity 调用 / Odometry）
3. **对比原图 3-4**：这张图展示了实际实现与开题规划的区别——我们没有用完整的 Eino Graph（多层嵌套），而是用 Eino ADK 做 Agent + 自制调度器，所以架构更扁平
4. **补充**: 可以在图右侧加一个 "交互控制" 侧边栏，包括 CLI 命令（/status, /history, /clear, /quit）和记忆模块（InMemorySessionManager 缓存机器人状态和对话历史）
